# One Word, First Thought

Entry for the make.fun bounty
[u-0xkianno-one-word-first-thought-106abaf8](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8)

`main.py` (Python 3.13, standard library only) writes exactly one word —
the first word that comes to mind — to `/output/entry.txt`.

The word is **psithurism**: the sound of wind in the trees.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
